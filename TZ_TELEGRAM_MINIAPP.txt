     (тот же бренд, шрифты, акцентный фиолетовый).

5. ТЕХНИЧЕСКИЙ СТЕК
================================================================================

Фронт:
  • React 19 + TypeScript           (как на основном сайте)
  • Vite                            (как на основном сайте)
  • styled-components               (тот же подход, переиспользовать
                                     src/styles/theme.ts и GlobalStyles.ts)
  • framer-motion                   (для микро-анимаций; в Mini App
                                     умеренно — Telegram не любит тяжёлой
                                     анимации, особенно на Android)
  • react-router-dom                (внутренняя навигация Mini App)
  • @twa-dev/sdk или @telegram-apps/sdk-react
                                    (типизированный доступ к Telegram WebApp API)

Бэкенд (новый, для Mini App):
  • Vercel Serverless Functions ИЛИ Cloudflare Workers
  • Эндпоинты:
      POST /api/brief                  отправка брифа в чат -1003746079351
      POST /api/lead                   быстрый лид (имя+контакт+вопрос)
      GET  /api/cases                  список кейсов (если выносим из статики)
      POST /api/calc                   расчёт стоимости (если логика на сервере)
      POST /api/subscribe              подписка на рассылку
      POST /api/booking                бронь консультации
  • Все эндпоинты валидируют Telegram initData по HMAC-SHA256
    (правила: https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app).
  • Хранилище: Vercel KV / Cloudflare KV / Supabase — по контексту
    (для лидов, подписок, броней).
  • Секреты: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID — только серверные env,
    из VITE_-префикса убрать.

Хостинг:
  • Mini App деплоить на отдельный поддомен — например,
    https://app.sintara.io (или https://tma.sintara.io).
  • HTTPS обязателен (Telegram требует).

Привязка к боту:
  • После деплоя в @BotFather:
      /mybots → Sintara_bot → Bot Settings → Configure Mini App
      указать URL https://app.sintara.io
  • Меню-кнопка бота:
      /mybots → Menu Button → текст «Открыть студию»,
      URL = https://app.sintara.io
  • Команды бота (/setcommands):
      start    — Запустить Sintara
      brief    — Заполнить бриф
      services — Услуги
      contact  — Связаться

6. НЕФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
================================================================================

Производительность:
  • TTI < 2с на 4G.
  • Бандл инициализации < 200KB gzip (Telegram открывает Mini App
    в WebView — лишние мегабайты больно).
  • Code splitting по экранам.
  • Изображения — WebP/AVIF, lazy-load, фиксированные размеры
    (чтобы не было layout shift).
  • Никакой 3D / тяжёлой графики (на сайте Three.js удалён —
    в Mini App тем более не тащим).

Доступность:
  • WCAG AA по контрасту.
  • Все интерактивные элементы достижимы клавиатурой.
  • Корректная работа со screen reader.

Локализация:
  • RU + EN, переиспользовать словари из src/context/LanguageContext.tsx.
  • Авто-определение языка по Telegram.WebApp.initDataUnsafe.user.language_code,
    с возможностью переключить вручную.

Безопасность:
  • Токен бота — только на сервере.
  • Все запросы с фронта — с заголовком X-Telegram-Init-Data,
    сервер валидирует подпись.
  • Rate limiting на /api/brief (5 запросов / IP / час) — защита от спама.
  • Без хранения PII в localStorage сверх необходимого
    (черновик брифа можно — это данные самого пользователя).

Аналитика:
  • Cобытия: open_app, start_brief, finish_step_N, submit_brief,
    open_service, open_case, click_calc, click_contact, lang_switch.
  • Стек: Yandex.Metrica / Plausible (без cookies, GDPR-friendly).
